# OOP-LAB-01

This repository contains C++ programs for OOP Lab 01 exercises.

## Tasks

### Task 1 - Hello World Program
**File:** `task1.cpp`

A basic C++ program that includes `<iostream>`, uses `namespace std`, contains a `main()` function, and prints "Welcome to OOP Lab 01".

**Compile and Run:**
```bash
g++ -o task1 task1.cpp
./task1
```

### Task 2 - Integer Input/Output
**File:** `task2.cpp`

A program that takes an integer input from the user and displays the entered value using `cout`.

**Compile and Run:**
```bash
g++ -o task2 task2.cpp
./task2
```

### Task 3 - Multiple Data Types
**File:** `task3.cpp`

A program that declares variables of type `int`, `float`, `double`, `char`, and `bool`. It takes input for each variable and displays their values.

**Compile and Run:**
```bash
g++ -o task3 task3.cpp
./task3
```

### Task 4 - sizeof() Function
**File:** `task4.cpp`

A program that uses the `sizeof()` function to display the size (in bytes) of `int`, `float`, `double`, `char`, and `bool`.

**Compile and Run:**
```bash
g++ -o task4 task4.cpp
./task4
```

## Requirements
- C++ compiler (g++ recommended)
- Standard C++ library

## Compilation
All programs can be compiled using g++ with the standard flags:
```bash
g++ -o <output_name> <source_file.cpp>
```
